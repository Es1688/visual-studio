# ADR-0003: HTML/CSS-шаблоны + Playwright для compose

Статус: accepted (2026-10-06)

## Контекст

Текст, логотипы, цены и CTA модель не рисует — нужно детерминированное
наложение (AGENTS.md). Один бриф должен давать баннер в нескольких aspect ratio
с одинаковым текстом. Альтернатива: JSON-описания + Pillow.

## Решение

`compose.py` рендерит `templates/*.html` (текст/лого/CTA — data-поля) через
headless Chromium (Playwright). Раскладка под все aspect ratio — на CSS
(media/aspect-ratio), а не вручную. Зависимость playwright добавляется на P4.

## Последствия

- Плюс: корректная типографика, web-шрифты, авто-переносы, отзывчивая раскладка
  из одного шаблона; HTML правится без кода.
- Минус: тяжёлая зависимость (~Chromium) — поэтому ставится на P4, не в P0.
- Рендер детерминирован: одинаковые вход → одинаковый пиксельный выход.
