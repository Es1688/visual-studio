# ADR-0001: fal.ai как провайдер этапа 1

Статус: accepted (2026-10-06)

## Контекст

Этапу 1 нужны text→image, редактирование по reference, inpainting, upscale и
удаление фона за единым интерфейсом; стадия P2 требует добавления второго
провайдера/модели без правок скиллов.

## Решение

Основной провайдер — fal.ai (шлюз): FLUX (text→image), FLUX Kontext
(reference-редактирование), FLUX Fill (inpaint), upscale и bg-removal — один
queue-API и один ключ (`FAL_KEY`). Адаптер в `gen_image.py` остаётся
провайдеро-независимым: смена — флагом `--model`, прямой провайдер (OpenAI,
Google) добавляется новым адаптером за тем же интерфейсом.

## Последствия

- Вторая модель для P2 — почти бесплатно (другой эндпоинт того же шлюза).
- Один биллинг и один ключ упрощают лимиты расходов.
- Минус: зависимость от одного вендора на весь этап 1.
- Цены в `config/capabilities.yaml` — заглушки (`verify_price: true`);
  проверка цен, лимитов и условий по документации — первый шаг P1.
