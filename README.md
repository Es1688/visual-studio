# media-studio — Image Studio (этап 1)

Рекламные изображения и баннеры над облачными провайдерами (fal.ai):
генерация, редактирование по reference, детерминированное наложение текста/CTA,
QC и экспорт под площадки.

- Правила агента: [AGENTS.md](AGENTS.md)
- Решения: [docs/adr/](docs/adr/)
